## Formatter flags
- **Letterhead** (para 1-16, 1-35): AR 25-50 para 1-16b requires the computer-generated letterhead from APD's template with the DoD seal and complete standardized mailing address (ZIP+4, para 1-35). The prototype prints a highlighted text placeholder; the product must load the official template and the user's real address.
- **ARIMS record number** (para 2-4a(2)): Required after the office symbol (para 2-4a(2)); depends on the record type (arims.army.mil). Not in the original, so a highlighted placeholder was left.
- **Date** (para 2-4a(3)): Para 2-4a(3)(b): the date goes on after signing (or in a text box for digital signature, app F). The typed date was kept and reformatted.
- **Subject capitalization** (para 2-4a(6), figure 2-1): AR 25-50 requires "SUBJECT:" in capitals and 10 words or fewer, but the regulation text does not state a capitalization rule for the subject words. Figures show initial capitals; converted to match the figures. Confirm with local SOP.
- **References paragraph** (para 1-30, 2-4b(1)(a)): Para 1-30 and 2-4b(1)(a): references go in the first paragraph. The original already led with the reference; kept as paragraph 1.
- **POC** (para 1-23, 2-4b(1)(e)): Point of contact is in the last paragraph, as para 1-23a / 2-4b(1)(e) require. Contact details are fictional placeholders.
- **Authority line** (para 2-4c(1), 6-4b): None added: only used when someone signs for the commander (para 2-4c(1)). The user must say whether one applies; signature block placed on the 5th line below the text.
- **Branch abbreviation** (para 6-4c, 6-4f): Para 6-4c says branch must be abbreviated, per DA Pam 611-21 (not fetched in this prototype). Left highlighted instead of guessing the code.
- **Postscript** (para 1-29): "P.S. Thanks for your help with this change." — para 1-29: do not use postscripts in Army correspondence. It is the writer's content, so it is held out of the layout and listed in the change log for approval; the writer can cut it or move the thought into the body.
- **Font** (para 1-19): Para 1-19 leaves font type to Army senior leaders (12 pt recommended). Arial 12 used as a placeholder profile setting; set the unit's font in the profile.
- **Paragraph length / one page** (para 1-39b): Para 1-39b(3),(7): paragraphs of no more than 10 lines; one-page memos. Both met here (checked visually in the PDF).
